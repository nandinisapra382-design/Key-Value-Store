# C++ Key-Value Store
An in-memory key-value database built from scratch in C++ to explore system design, memory management, and network programming.

## Core Features
* **Custom Data Structures:** Implemented custom Hash Tables and AVL trees from scratch without relying on the C++ Standard Template Library (STL).
* **Network Programming:** Built a TCP server using POSIX sockets to handle client-server communication.
* **Concurrency:** Utilized thread pools to manage multiple simultaneous client connections efficiently.
